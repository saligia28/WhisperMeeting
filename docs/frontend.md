### 功能需求
- 录音控制：按钮状态需与后端 `/recording/start`, `/recording/stop` 对接。
- 实时字幕：轮询后端 `/meetings/{id}/stream`（预留）或使用 WebSocket 推送。
- 重点标记：用户可选定字幕段落添加关键点，存储在 `MeetingRepository`。
- 摘要/行动项：调用 `/meetings/{id}/summary` 获取结构化结果。
- 导出：触发本地脚本或 API，将 Markdown 推送至目标平台（见 `automation.md`）。
